SAÉ 2.2 : Exploration algorithmique

Assistant personnel de voyage multimodal — IHM, POO et modélisation par graphes.

Voir sur GitHub Retour aux projets

Description

Ce projet consiste à créer un assistant personnel de voyage, logiciel de calculer, visualiser et comparer des itinéraires pour un utilisateur donné. Il est divisé en 3 parties : IHM, POO et Graphe. Au début, nous devons modéliser un réseau qui est composé de 5 villes et les arêtes (connexions) entre eux avec les 3 critères correspondant aux préférences de l’utilisateur : CO2, Prix, Temps en créant un graphe. Cela étant, nous avons créé un fichier csv qui comprend les poids du graphe pour implémenter et lancer l’algorithme KPCC. Nous avons développé ce logiciel en mettant les correspondances entre les villes pour créer un modèle multimodalités. Enfin, nous devons concevoir une interface basse fidélité en utilisant le logiciel Figma dans le but de montrer à quoi devrait ressembler l’interface finale. Cette interface finale va être conçue par le logiciel SceneBuilder pour implémenter dans le code à la fin.
