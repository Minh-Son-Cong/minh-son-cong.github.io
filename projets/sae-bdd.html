SAÉ 1.04 et 2.04 : Introduction aux bases de données

Modélisation Merise (MCD/MLD), SQL, PostgreSQL et exploitation de données réelles.

Voir sur GitHub Retour aux projets

Description

Au début, mon groupe a fait un système de base de données pour la gestion d’un service d’aide à domicile. L’objectif est de relier les clients, les prestataires et les services afin de faciliter la planification, la facturation et le suivi de la qualité et aider les utilisateurs à accéder plus rapidement à de grandes données. Après, quand j’ai beaucoup avancé dans le langage SQL, j’ai exploité une base de données sur le taux d’application et admission des candidats de Parcoursup. J’ai analysé les fichiers csv, les ai importés dans notre base de données et fait les requêtes et les vues pour mieux accéder aux informations nécessaires. J’ai ventilé aussi ce que j’ai importé pour avoir les tables nécessaires afin de mieux gérer les informations.

Techniques
